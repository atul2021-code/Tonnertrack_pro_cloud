Security & Source Code Protection

🛡️
Zero Exposed Credentials in Source Code: This application is completely static and serverless. There are no Google API keys, tokens, secret passwords, or external database credentials embedded anywhere in the code.
Client-Side Privacy & Sandboxing:

• All fleet and inventory data is stored solely inside your browser's private localStorage.

• No data, telemetry, or user inputs are transmitted to third-party tracking servers.

AES-256 Backup Encryption:

When downloading inventory backups, enter an optional password to encrypt your database with native browser AES-GCM (PBKDF2 100,000 iterations). Unauthorized users cannot inspect backup files without your passphrase.
